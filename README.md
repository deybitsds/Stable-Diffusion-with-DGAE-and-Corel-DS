## 📋 Execution Order

### Task 2: LoRA Fine-tuning (Pre-trained Model)

```bash
# Step 1: Prepare dataset
python 2A-prepare_corel_dataset.py --data-dir data/corel --base-dir .

# Step 2: Train LoRA
python 2B-train-lora-corel.py --data-dir training_data/corel/corel_all --output-dir training_data/corel_models --epochs 200

# Step 3: Generate images
python 2C-generate-lora-corel.py --lora-dir training_data/corel_models --num-images 8
```

**Outputs:**
- `training_data/corel/` - Processed datasets
- `training_data/corel_models/lora_*.safetensors` - Trained LoRA weights
- `generated_images/corel_*.png` - Generated images
- `figs/corel_dataset_samples.png` - Dataset visualization

### Task 3: Train from Scratch

```bash
# Step 1: Train VAE
python 3A-train-vae-corel.py --data-dir training_data/corel/corel_all --output-dir models/vae_models --epochs 300

# Step 2: Train diffusion model
python 3B-train-diffusion-from-scratch-corel.py \
    --vae-checkpoint models/vae_models/best_model.pt \
    --image-dir training_data/corel/corel_all \
    --output-dir models/diffusion_models \
    --epochs 400

# Step 3: Generate samples
python 3C-generate-samples-corel.py \
    --diffusion-checkpoint models/diffusion_models/best_model.pt \
    --vae-checkpoint models/vae_models/best_model.pt \
    --num-images 16
```

**Outputs:**
- `models/vae_models/` - VAE checkpoints and visualizations
- `models/diffusion_models/` - Diffusion model checkpoints and samples
- Generated images from diffusion model

### Task 4: DGAE (Diffusion-Guided Autoencoder)

```bash
# Step 1: Train DGAE
python 4A-train-dgae-corel.py \
    --data-dir training_data/corel/corel_all \
    --lora-dir training_data/corel_models \
    --output-dir models/dgae_models \
    --epochs 300

# Step 2: Extract features
python 4B-extract-features-corel.py \
    --checkpoint models/dgae_models/best_model.pt \
    --data-dir training_data/corel/corel_all \
    --output-dir features
```

**Outputs:**
- `models/dgae_models/` - DGAE checkpoints and visualizations
- `features/dgae_features.*` - Extracted latent features

### Task 5: Self-Supervised Learning and Clustering

```bash
# Step 1: Train SimCLR
python 5A-simclr_corel.py \
    --data-dir training_data/corel/corel_all \
    --output-dir models/simclr_models \
    --epochs 100 \
    --extract-features \
    --evaluate-clustering

# Step 2: Train CNN-JEPA
python 5D-cnn-jepa_corel.py \
    --data-dir training_data/corel/corel_all \
    --output-dir models/cnn_jepa_models \
    --epochs 100 \
    --extract-features \
    --evaluate-clustering

# Step 3: Compare clustering
python 5E-compare-clustering.py \
    --simclr-features features/simclr_features.npy \
    --cnn-jepa-features features/cnn_jepa_features.npy \
    --dgae-features features/dgae_features.npy \
    --data-dir training_data/corel/corel_all \
    --output-dir features
```

**Outputs:**
- `models/simclr_models/` - SimCLR checkpoints
- `models/cnn_jepa_models/` - CNN-JEPA checkpoints
- `features/*_features.*` - Extracted features for all methods
- Clustering comparison visualizations and metrics

## ⚠️ Important Notes

### Directory Paths

- **All scripts expect to be run from `codes/` directory**
- Use `--base-dir .` when running from `codes/` (this is the default)
- For cloud execution, set `--base-dir /workspace` or your cloud path

### File Dependencies

**Task 2 → Task 4:**
- Task 4 (DGAE) requires LoRA models from Task 2
- Make sure `training_data/corel_models/` contains trained LoRA weights before running Task 4

**Task 3:**
- Task 3B requires VAE from Task 3A
- Task 3C requires both VAE and diffusion model
- All models are saved in `models/` subdirectory

**Task 5:**
- Task 5E requires features from Tasks 4 and 5A, 5D
- Run feature extraction with `--extract-features` flag
- All models are saved in `models/` subdirectory

### Common Issues

1. **"File not found" errors:**
   - Verify you're running scripts from `codes/` directory
   - Check that `data/corel/` contains your images
   - Ensure previous tasks completed successfully

2. **"No module named X":**
   - Install missing dependencies: `pip install X`
   - Check you're in the correct Python environment

3. **CUDA out of memory:**
   - Reduce batch size: `--batch-size 1`
   - Increase gradient accumulation: `--grad-accum 8`
   - Reduce image resolution: `--resolution 384`

4. **Model paths:**
   - LoRA models: `training_data/corel_models/`
   - Other models: `models/vae_models/`, `models/diffusion_models/`, etc.
   - All models are organized in the `models/` subdirectory
